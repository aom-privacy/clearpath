# CLEARPATH — website

Bilingual (English + Spanish) website for CLEARPATH, construction cost
control in Los Cabos. Static site, no build step, no framework, no trackers.

**Live site:** https://clearpath.mx/ (English) and https://clearpath.mx/es/
(Spanish). Also at https://aom-privacy.github.io/clearpath/ and
https://aom-privacy.github.io/clearpath/es/.

## Files

- `index.html` — the whole page in English. Images and the hero video are
  inlined as data URIs (see note below), so the page works with just this
  file plus `styles.css`.
- `es/index.html` — the same page in Spanish, with its own Spanish chart.
  Linked from the English page with the EN | ES switcher in the header.
- `styles.css` — the built stylesheet (generated from `styles.template.css`
  by `build.py`, with the background photos inlined).
- `index.template.html`, `index.template.es.html`, `styles.template.css`,
  `build.py` — sources. Rebuild with `python3 build.py` after editing a
  template or the stylesheet; it builds both languages.
- `assets/` — original asset files (logo, photos, charts, hero video), kept
  in the local workspace copy for reference and for future replacement.
  They are not pushed to the repo (binary files cannot be pushed through
  the GitHub connector used here). The Spanish chart is generated by
  `assets/make_chart_es.py` (English: `assets/make_chart_en.py`).

## Note on inlined assets

The GitHub connector used to publish this site can only push UTF-8 text
files, not binary files. That is why the logo, photos, chart and video are
embedded in the HTML/CSS as base64 data URIs instead of living in an
`assets/` folder on the repo. The originals are kept in `assets/` in the
local workspace copy.
If binary upload becomes possible, the data URIs can be swapped for plain
`assets/...` paths.
